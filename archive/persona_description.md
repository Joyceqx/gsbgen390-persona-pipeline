# Persona Description — used by Condition B

This is the "short biographical description" baseline, sitting between demographics-only and the interview-conditioned personas. The pipeline reads this file verbatim and pastes it into the LLM's system prompt as the only persona material for Condition B.

**Important hygiene:** write this *without referring to the interview transcripts*. Either (a) write it yourself based on how you'd describe yourself to a stranger, or (b) ask one friend / family member who knows you well to write a paragraph. Do not generate it from Cookiy's transcript — that contaminates the comparison.

Replace this entire file with 1–3 paragraphs (~150–300 words). Use first or third person, your call. Cover:

- Who you are at a high level (role, stage of life, where you are)
- A few salient personality traits or values (in your own words, not BFI-speak)
- What's currently occupying your attention / energy
- Anything that would help a stranger predict how you'd answer everyday questions about your life and preferences

When you've written your version, save (overwriting this file) and the pipeline will pick it up automatically. If this placeholder text is still here when the pipeline runs, Condition B is skipped.
